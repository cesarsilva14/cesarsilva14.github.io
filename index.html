🚀 sharecli - Share Files With Short Links Instantly

Turn a web page, a Markdown document or any file on your computer into a tidy short link you can send to anyone. The link lives on your own domain, and it runs for free on Cloudflare.

⬇️ Download sharecli

Visit this link to download the application.

🔍 What Is sharecli?

sharecli is a small helper that sits on your Windows computer and does one job extremely well: it takes something you want to show someone else and gives you a short, clean web address for it.

Instead of attaching a heavy file to an email, uploading to a random website, or sending a link that looks like a long string of letters and numbers, you end up with a link like yourdomain.com/launch-notes — short, readable, and yours.

Because the files and the links are stored on Cloudflare, there is no server for you to babysit. You do not need to rent hosting, and you do not need to keep your computer switched on for the link to work.

✨ What You Can Share

sharecli handles the everyday things people actually need to send:

  • HTML pages — a single web page, a report, a dashboard or a landing page, ready for someone to open in a browser.
  • Markdown documents — notes, guides, proposals and README files that turn into nicely formatted pages.
  • Files of all kinds — PDFs, images, spreadsheets, zip archives, contracts, screenshots.
  • Short links on your own domain — every share gets a tidy address instead of a long unreadable one.
  • Shares created by an AI agent — sharecli is built to be used by AI agents and coding assistants as well as by people typing commands themselves.

📥 Download and Install on Windows

Everything you need lives on the official releases page. Visit this link to download the application:

Get sharecli from GitHub Releases

What happens next:

  1. Click the button above. Your browser opens the releases page.
  2. The newest release is listed at the top of that page.
  3. Download the file offered there and save it to your computer.
  4. When the download finishes, open the file from your Downloads folder to start using sharecli.

🧭 Your First Share, Step by Step

You do not need to know how to program. You only need to be able to type a short instruction and press Enter.

  1. Open the app. Double-click the sharecli file you downloaded. A simple text window opens, ready for your instruction.
  2. Point it at something. Type the name of the file you want to share and press Enter. If the file is on your Desktop, that is enough — no complicated paths required.
  3. Wait a moment. sharecli uploads the item and prepares the link for you. This usually takes only a few seconds.
  4. Copy your short link. When the process finishes, you get a short address on your own domain. Copy it.
  5. Send it to anyone. Paste the link into an email, a chat message or a document. Whoever opens it sees your page, document or file in their browser — no app required on their side.

If you use an AI agent or a coding assistant, the same job can be handed over to the agent instead. sharecli is designed to be called from those tools too, so the agent can create the share and hand you back the finished link.

💡 Why People Use It

  • Links look professional. A short address on your own domain carries more trust than a long random one from a stranger's website.
  • It is free to run. The storage and delivery side runs on Cloudflare, which keeps your costs at zero for normal everyday use.
  • Nothing to maintain. No server to update, no uptime to worry about, no hosting bill to check.
  • One tool, many file types. Web pages, Markdown documents and ordinary files all go through the same simple process.
  • Friendly to automation. It works when you type the instruction yourself, and it works when an AI agent does it for you.

🖥️ System Requirements

  • Windows 10 or Windows 11.
  • An internet connection, both for downloading and for creating links.
  • The built-in Windows terminal application, which is already on your computer.
  • A free Cloudflare account so your links can live on your own domain.
